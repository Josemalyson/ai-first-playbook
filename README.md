# IA First Engineering — Playbook

Referência de processo AI-First para squads em ambiente bancário, com um tutorial prático do BMAD Method 6.12.4 em Go, do zero até o pull request, incluindo um quality gate de pre-commit com loop de autocorreção do agente. A versão navegável está publicada em [https://josemalyson.github.io/ai-first-playbook/](https://josemalyson.github.io/ai-first-playbook/).
